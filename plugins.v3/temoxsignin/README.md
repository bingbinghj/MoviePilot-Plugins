# 中国特摄联盟自动登录

MoviePilot V3 插件，用于每天自动登录中国特摄联盟：

```text
http://bt.temox.com:8080
```

## 功能

- 支持站点访问前置算术验证，例如 `3 + 8 + 7 = ?`
- 自动解析 Discuz X3.4 登录表单并提交账号密码
- 登录成功通知会包含站点每日登录奖励提示：`每天登录 经验+1p 人气+1点 分享度+1 人品+1p`
- 支持 Cron 定时每天执行
- 支持配置页手动执行一次
- 支持远程命令 `/temox_signin`

## 配置

- `启用插件`：开启后注册定时任务
- `站点地址`：默认 `http://bt.temox.com:8080`
- `用户名` / `密码`：中国特摄联盟账号密码
- `Cron 表达式`：默认 `15 8 * * *`，即每天 08:15 执行
- `仅运行一次`：保存配置后执行一次，并在执行前自动关闭该开关
- `发送通知`：执行结束后尝试通过 MoviePilot 通知渠道发送结果

如果账号设置了 Discuz 安全提问，可填写安全提问编号和答案；未设置时保持默认 `0` 即可。

## V3 适配

版本 `2.0.0` 使用稳定 SDK，并兼容早期 V3 公开的插件基类入口。账号和配置键沿用原有名称。

- Cron 使用 MoviePilot 的 `TZ` 时区。
- “仅运行一次”在支持宿主一次性任务接口时延迟约 3 秒执行，早期 V3 直接执行；执行前持久化关闭开关。
- 停用或重载取消未执行的一次性任务。
- API 显式声明 Pydantic 响应模型，保留既有 JSON 字段。
- 每次请求结束后释放本次 HTTP 或 Redis 连接。
